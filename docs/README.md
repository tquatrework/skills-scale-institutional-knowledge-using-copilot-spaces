# OctoAcme Project Management Docs

Concise index for the OctoAcme project management process docs. These docs describe how OctoAcme plans work, coordinates delivery, manages risk, releases changes, and improves after each milestone.

## Process snapshot

- **Lifecycle:** initiation → planning → execution → release → retrospective
- **Roles:** Project Manager, Product Manager, developers, QA, and stakeholders
- **Cadence:** weekly PM/PdM syncs, team standups, and milestone-based stakeholder updates
